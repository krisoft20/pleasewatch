get it running

A fresh Ubuntu or Debian box, one script, and a free TMDB key.

on a fresh server

sudo apt-get update
sudo apt-get install -y curl git
curl -fsSL https://get.docker.com | sudo sh

sudo git clone https://github.com/krisoft20/pleasewatch /opt/pleasewatch
cd /opt/pleasewatch/deploy

If you forked the repo, use your fork URL instead.

For a real domain, point DNS at the server first. Caddy handles HTTPS. Then run:

sudo ./setup.sh --domain watch.example.com

For a plain IP or LAN test, run it without a domain and open http://your-server-ip:

sudo ./setup.sh

If you do not want to expose a test install yet, tunnel port 80 and open http://127.0.0.1:8080:

ssh -L 8080:127.0.0.1:80 user@your-server-ip

first run

  1. Open the URL printed by setup.sh.
  2. Register the first account. It becomes admin.
  3. Sign in and add a TMDB key on /onboarding.
  4. Open the app.

TMDB is the only required key for search and metadata. OMDB, Wyzie, qBittorrent, Jackett and Prowlarr can be configured later in /admin?tab=settings.

storage

Media is stored on the server filesystem. New installs default to /opt/pleasewatch/media, mounted as /media inside the containers.

For a real library, pick a server with actual storage or mount an extra disk first. Then set this in deploy/.env before running setup:

PW_MEDIA_DIR=/mnt/storage/pleasewatch

qBittorrent and pleasewatch both mount that path as /media, so downloads and processed files stay on the same disk.

update

cd /opt/pleasewatch
sudo git pull
cd deploy
sudo ./setup.sh

The setup script keeps the existing .env, database and media folders.

useful checks

cd /opt/pleasewatch/deploy
sudo docker compose -f docker-compose.simple.yml ps
sudo docker compose logs -f pleasewatch

local dev

Backend:

cd backend
TMDB_API_KEY=your_key cargo run

Frontend:

cd frontend
npm install
npm run dev

For local download testing, run Jackett or Prowlarr and qBittorrent separately, then set their URLs and API keys in the admin settings.
